# 首次安装与新手调试

starr 负责保存资料、注册 QQ 会话预设与执行诊断，用户负责账号登录、选择目录和确认角色人格。安装后无需让聊天模型编写插件、修改宿主安装目录或临时生成预设文件。

## 七步流程

1. **连接 QQ**：按教程启动 SnowLuma，登录机器人账号，启用 OneBot HTTP 与正向 WebSocket，填写实际端口、相同的访问令牌与允许回复的 QQ 号/群号。检查协议、账号在线和 WebSocket 握手。只连接本机 `127.0.0.1`；可选择稍后连接。Windows 令牌按当前用户加密，网页不回显、不写入草稿；也可用环境变量。
2. **创建角色**：新安装填写名字与时区。已有安装明确选择现有角色，避免向导覆盖旧资料。
3. **写下人格**：自行编辑，或填入基础模板后调整。模板不依赖模型调用；已有角色显示只读预览，修改由正式角色页完成。
4. **安放记忆**：选择记忆库与独立备份目录，角色到此步才正式创建。默认接受新的空目录；明确勾选后允许使用带 `.obsidian` 目录的现有库，保留原笔记与设置。目录读写和数据库完整性检查通过后继续。
5. **连接 B站**：可打开官网登录并保存接入意向，也可跳过。完成向导后在“逐光而行 → B站 → 账号”保存 Cookie 或指定环境变量，再验证登录、选择模型和允许对象；各通道与分享、动态分别开启。浏览器登录不会自动继承为插件登录。
6. **扩展感官**：可跳过说话、听写、看图等模型，之后在能力页配置。填写服务地址、密钥环境变量名称和模型标识；真实密钥由启动环境管理。已有配置先读取，只保存手动修改的字段；并发变化拒绝覆盖。
7. **准备出发**：汇总真实结果。角色存在、人格非空、记忆库检查通过；若选择现在连接 QQ，协议检查须通过。启用 QQ 还需选择 DSH 聊天服务与模型并填写允许名单。只有管理员勾选“完成向导后启用 QQ 自动回复”，完成后才启动收发；不勾选则保存配置并暂停。

第六步还可读取 DSH 已有聊天模型连接，在用户点击后发送一条合成后台诊断请求，检测模型通道与工具调用格式。测试不读取私人记忆、不实际执行诊断工具，也不更改 DSH 默认模型；可能消耗少量模型额度。

## 检查结果的含义

| 结果            | 能说明什么                                    | 还不能说明什么                            |
| --------------- | --------------------------------------------- | ----------------------------------------- |
| 预设已注册      | 宿主接受预设定义                              | 子插件已加载或消息能够回复                |
| 预设检查通过    | 宿主预设列表中存在该项且没有加载诊断错误      | 真实模型执行与 QQ 收发正常                |
| 端口可达        | 指定的两个本机 TCP 端口正在监听               | 一定是 SnowLuma、账号已登录、协议认证通过 |
| QQ 协议检查通过 | HTTP 协议、账号在线与正向 WebSocket 握手通过  | 真实模型生成、QQ 收到回复或历史消息补收   |
| 记忆检查通过    | 记忆/备份目录可读写，当前角色数据库完整性正常 | 旧格式已迁移、自动定时备份已启用          |
| 模型检查通过    | 后台模型返回预期诊断工具格式                  | 完整会话循环或 QQ 平台回复已通过          |
| 模型部分通过    | 模型有文本响应                                | 预期工具格式已支持                        |
| 完成新手调试    | 基础资料与要求的检查已通过                    | QQ/B站或所有媒体能力已可用                |

## 进度与失败恢复

草稿、当前步骤、检查结果和完成时间保存在安装数据库中，使用修订号防止两个页面相互覆盖。刷新或重启后继续，控制台顶部可再次打开“新手调试”。修改端口或令牌变量使旧检查失效；切换角色使记忆检查和完成状态失效。创建请求重试沿用已创建角色，不重复初始化目录。已完成安装后，对话页修改的连接选项会同步回向导，防止再次调试覆盖较新的配置。

首次提醒可以暂时关闭，不会抢走当前会话。尚未完成时，控制台保留提醒与入口。向导没有网络连接时仍可创建角色、提示词和本地记忆库，QQ、B站及模型连接可稍后处理。

bot 自主调整日常配置另由权限页控制，默认关闭。授权后允许修改每次召回条数、主动行动冷却和说话速度，且有单次幅度限制与审计；新手向导不能由模型消息替代管理员操作。

完整 QQ 使用说明、去重与“发送待核对”的含义见 [QQ 连接与故障处理](QQ.md)。QQ 驱动由插件实现，不需要聊天模型编写桥接脚本。
