# v0.2.4：让相处延续，让页面回到日常

本版围绕同一角色的持续相处、自由笔记和日常操作重新整理。首次打开仍可先配置聊天，B站和媒体按需要接入。

## 记忆与成长

- 日记继续独立定时保存；其他新记忆统一为自由笔记，新增目录为“笔记”。兼容旧人物、兴趣、约定与概览记录，升级不会自动搬动已有文件。
- 新增 `starr_memory_update`。角色先读取可见笔记，再用当前修订号更新标题、正文或长期理解标记；保留原来源、时间与可见范围，记录修改前后正文和理由。日记不允许经此工具改写。
- 长期理解优先进入新会话的有限记忆预算；私密笔记继续受来源会话和角色隔离。换会话后能够继续取得已经保存的相处理解，但没有落笔的短期上下文不会自动变成永久记忆。
- 合并、关联、归档和恢复沿用共享维护服务。固定整理、周/月/年概览任务退役，不再为分类反复生成笔记。
- 首页“成长”只展示实际保存的长期理解和角色修订记录，不计算虚构分数，也不把管理员编辑称作角色成长。

## 自主活动与会话

- 同类自主活动、B站后台活动、同类型日记按角色和来源复用会话，支持冷恢复；正在运行的会话拒绝被另一轮抢用。
- 每轮临时工具与监听结束后释放，避免复用时仍调用上一轮回调。使用宿主真实标题服务，正常用户自定义标题保留。
- QQ 来信优先展示本轮真实消息，角色资料与接续资料随后注入，减少重复角色契约。
- 群观察、群自主参与、自主总开关同时开启且未暂停时，清醒状态的普通群消息也能交给模型判断回应或保持安静。仅观察、沉睡、禁止群和暂停仍有效。
- 保留回复后默认 150 秒接听，同一回合收到补充后继续；没有改成每句都新开宿主会话。平台收发与模型执行仍需安装后用真实账号验收。
- 移除插件内 Tabbit 工具、配置、页面与后台执行链。电脑上的 Tabbit、宿主自己的浏览工具、B站阅读和视觉能力不受影响。

## 页面

- 聊天、感受与表达、自主活动、记忆四个工作区。B站的账号、浏览和发布合并到同一个入口的三个标签。
- 常用设置在功能页直接展示，高级参数按组折叠；搜索支持日常说法，并能展开、定位目标字段。旧地址跳转到当前入口。
- 同一页角色设置一次保存；保存中、成功、失败和还原状态明确。保存失败保留输入；切页、切角色、关闭网页保护未保存内容。角色资料、连接等专用表单仍独立保存，并明确按钮的作用范围。
- 首页场景与四段实际预览保留，功能页不因继续下滑而切到下一功能；显示真实近况、检查时间与异常入口。刷新失败标为旧数据，不继续宣称在线。
- 默认列表阅读记忆；可切换时间线、长期理解或三维星图。桌面长文右侧独立滚动，支持键盘翻页，正文保留换行、不截断。
- 保留诗意首页与导航、普通功能名称、无边框、无色局部模糊和文字阴影。四芒星与折射使用共享交互层；键盘焦点、禁用状态和减少动态保持可辨。
- 历代样式合并为基础文件与本版产品层；功能页背景限制为每秒 30 帧，首页继续自适应品质。

## 升级与数据

插件发行包只包含代码和构建后的界面，不含角色、记忆、凭据或模型。普通升级不自动精简旧记忆，不修改可见范围，不删除旧宿主会话。

`scripts/prepare-memory-review.mjs` 为有明确精简方案的管理员创建**独立审核副本**。只支持可读目录格式 2，拒绝覆盖、输入输出重叠、来源遗漏与跨私密范围合并；完整归档旧笔记，并核验日记数据库行和原文件。审核副本关闭 QQ、B站、自主活动与定时任务，不能直接用它覆盖生产运行库。

本次交付为审核版，未安装或启动生产环境的新插件，也未向真实 QQ/B站发送测试消息。测试、页面实测和未联调范围见 [验证记录](VERIFICATION-V024.md)，页面位置见 [页面清单](WEBUI-V024.md)。
