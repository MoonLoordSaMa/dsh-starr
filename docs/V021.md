# v0.2.1：自主活动、群聊参与与清晰的功能入口

斯塔可以把真实兴趣、未完项目和分享意愿保存为持续目的，记录进展、下一步和接续时间。主动活动由角色结合真实经历自行选择，情绪影响表达与投入；平静、低落或愉快都能获得日常主动机会。

## 主动活动与群聊

- 新增持续目的查询与推进工具。进度保存在角色数据库，重启后继续；修订冲突不会覆盖已有进度。
- 开启“观察允许群的日常消息”后，未被 @ 的消息可以保存为观察记录，仍不立即唤醒模型。
- 开启“允许自主参与群聊”并选择社交级范围后，可从已有允许群的近期话题选择参与；群冷却、待处理来信、暂停、连接账号与对象名单都会重新检查。
- 新增分享意愿工具：只能从当前会话可见且已明确共享的记忆形成给主人分享的目的；创建意愿不立即发送。撤回共享或归档记忆会阻止后续执行。
- 网页提供“采用活跃探索频率”：20分钟日常评估、10分钟冷却、近24小时48次评估、8次外发与120000令牌预算。它只调整频率和预算，不自动扩大对象或能力授权。
- 每次机会最多尝试一次外发，未知回执保留待核对，不重发。

## 自主管理记忆

角色自行决定哪些真实经历值得保存、关联和淡忘，无需要求用户分类或标注。普通记忆不填类型即可保存。授予归档权限后，角色可以归档本会话可见的普通记忆，正文和审计保留，可恢复；日记受独立保护。历史分类格式保持兼容，不在升级时批量清空旧库。

## GIF与网页能力

GIF附件识别实际文件头，经FFmpeg解码后生成关键帧拼图，接入原有图片输入和图片分析工具。单次最多分析前12秒、24个采样帧，再选最多8格提交；附件字节数、原始画布、执行时间和输出大小均有限制。需要本机FFmpeg及已配置的视觉模型，不能从静态占位文字猜测动图内容。

新增Tabbit网页阅读工具，可读取管理员允许站点的正文、链接，并按需分析当前页截图。使用稳定启动器和插件自己的页面，遵守真实回执及资源分页；不向角色开放任意浏览器脚本。网页截图分析与已有See Now短片段工具沿用同一视觉配置。当前不是完整网页操作代理，也没有新增持续桌面监视或系统音频理解。

## 页面导航

顶部整理为四个功能区：角色与记忆、聊天设置、浏览及媒体、配置维护。导航保留诗意名称，并附直白说明；各区左栏显示全部功能。增加共享记忆、分段回复、主动性、网页与视觉的快捷入口，以及随处可达的“查找功能”。保留已有星庭场景。

## 升级与边界

安装包为 `dsh-starr-0.2.1.tgz`。保留原运行目录、记忆库和备份库，完全退出DSH后更新插件并重新打开。网页应显示v0.2.1。新增外部能力默认关闭，不会自行扩大群名单、打开浏览器授权或抬高预算。

真实平台外发和生产模型效果仍需在安装后按已授权环境验证；合成回执测试不等于真实群消息已送达。
