# 表情包、曲库与密钥管理

这些操作从管理员网页执行，仅作用于当前角色。不会给bot新增删除资源或修改凭据的工具。

## 表情库

每张表情卡片提供删除图标，详情窗口也能删除。确认后，表情从可选列表中移除，图片、收藏和关键词元数据移至该角色表情目录的`.trash`。原文件缺失时仍可清理残留记录，页面不会把不存在的图片描述成可恢复。

此处为回收删除，尚未提供网页恢复或清空回收目录入口；误删后请先保留`.trash`和完整备份，不要手动清空。重新导入相同图片会建立新的有效记录。

## 曲库与翻唱成品

- 每个曲库音频可单独删除，来源索引同步移除，来源元数据和文件保留在曲库`.trash`，已有翻唱成品保留。
- 默认参考音色也能点击删除。弹窗明确说明将解除默认引用；确认后按配置修订校验执行，之后需要重新选择参考音色。仅旧接口未明确确认解除引用时仍拒绝删除。
- 翻唱成品可单独删除，失败或已清理的记录也可从列表移除。内部转换记录保留，已移除成品不能继续播放或命中复用缓存。
- “清理生成成品”会永久清理所有当前角色成品文件，保留音源、参考音色和转换记录；确认弹窗会说明这是永久文件清理，与单项回收删除不同。
- 转换进行中暂时禁止删除与清理，完成或中止后再操作。页面可见时每3秒更新状态，返回窗口也会重新检查，避免后台完成后仍显示禁用。临时文件清理失败也会释放转换锁。文件系统或数据库失败时尽量还原，发生回收目录冲突或联接时停止处理。

插件不删除管理员指定的外部模型目录、共享Breeze音色文件或模型权重。

## 已保存媒体密钥

听、说、看页可清除当前角色已加密保存的独立或共用密钥。共用密钥的确认窗口说明会影响所有沿用该连接的能力。启动环境中的密钥不受此操作影响，需要在启动环境中另行移除。服务地址和模型配置保留，可改为停用或重新填写。
