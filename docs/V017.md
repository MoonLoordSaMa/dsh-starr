# v0.1.7：听说看唱与共同记忆

本版把媒体连接、当前角色的记忆和QQ/B站会话接回同一条调用链。外部能力按实际回执区分配置、发现、调用成功与投递结果，连接正常不代表模型或平台所有操作均可用。

## 新用户的配置顺序

1. 首次向导创建角色、人格、记忆与备份目录，连接SnowLuma，再按需扫码连接B站。令牌与QQ密码不是同一种东西。
2. 在媒体工作区选择听写、说话、看图的使用方式。日常选项放在顶部，程序路径、设备与超时放在高级配置。
3. 听写默认自动选择：已有共用兼容地址则沿用；没有则使用免费本地Whisper。点击“准备免费听写”创建独立Python环境并安装依赖，需要已安装Python和网络。首次转写按需取得开源权重；免费指无API调用费用，仍占用本机算力和磁盘。也可直接选择免费本地模式，或填写远程兼容地址、模型与密钥。
4. 说话可扫描管理员确认的本地模型目录，应用Breeze候选，或配置远程兼容TTS服务。扫描只证明文件/模型清单存在。Breeze允许提交WAV参考录音与准确原文，取得持久化音色编号后自动选用。这是参考音频编码，不是重新训练基础模型。云端训练没有统一协议，须在服务商建立音色后填写编号。
5. 唱歌优先使用本地SoulX。确认模型、程序与推理设备，导入音源及参考音色，再生成翻唱。音源与成品均经FFmpeg限制到45秒内，参考最多30秒；结果保存在当前角色曲库。同配置可复用缓存。
6. 视觉默认使用DSH已配置的视觉模型，无需额外地址或密钥；可在视觉页选择宿主清单中支持图片的模型，也可自动沿用当前会话、角色聊天或DSH默认模型。模型必须明确声明支持图片，纯文字模型会拒绝。共用或独立云端兼容接口仍可选。屏幕、摄像头权限独立开启，单次最多12秒；B站视频只分析最多45秒片段内实际采到的关键帧，默认30秒。
7. 分别用真实输入测试能力，再开启角色自动调用所需开关。

免费听写的模型大小与云端模型名称分别保存。tiny/base下载更少，small为默认平衡选择，medium/large-v3需要更高资源。模型目录可指向完整的faster-whisper格式模型；GGUF、原版PyTorch权重不能直接混用。

听写运行环境固定使用已经验证的faster-whisper 1.2.1与PyAV 15.1.0，避免新版PyAV移除解码参数导致首次使用失败。Windows子进程统一使用UTF-8，避免中文转写乱码。

## 本地模型的唯一在线与卸载

插件托管的Breeze、SoulX与免费Whisper共用一个本地模型许可，跨角色、运行目录和宿主生效。当前模型推理期间，其他本地模型调用明确拒绝；当前模型空闲时，切换会先卸载它并确认进程退出，再加载下一模型。同一模型的请求复用现有进程。

最后一次请求结束后，Breeze与SoulX闲置满300秒自动退出，旧配置中的0秒或更长时间不会取消此规则。Whisper按次运行，转写结束立即退出。停止超时不会释放加载许可，避免旧模型仍活着时又启动新模型。

手动启动的本机兼容服务没有可靠的卸载协议，本版拒绝将其作为媒体兼容接口连接；请改为插件托管的本地模式。真正运行在远程机器的兼容服务可以使用，不占本机模型许可。本规则只管理starr托管的Breeze、SoulX与Whisper，不会终止其他软件自行启动的模型进程。DSH宿主视觉沿用宿主的模型生命周期，不另启本地视觉进程；starr暂未提供本地视觉模型托管与卸载。

本机Breeze现有unia音色通过真实生成测试；新增参考音色编码在当前Breeze v0.1.3环境中发生引擎访问冲突退出。插件会显示失败并保留原音色配置，不把它当作建音色成功；需要修复该引擎与模型的兼容性后再使用此功能。

## 看：结合See Now

画面采集和关键帧选择使用 `SAOS-3624/dsh-see-now` 0.0.10的核心，保留Apache-2.0许可与NOTICE。上游信息见 `src/vendor/see-now/UPSTREAM.md`。

流程是画面采集 → 变化量筛选 → 关键帧拼图 → 当前配置的视觉模型。它提供“看见”的输入，不能独立完成视觉理解。本版按次调用，不启动持续监控，不捆绑上游整套悬浮窗与语音助手。每次返回实际采样时间，明确区分“看到片段画面”“听到音频”和“看完整视频”。

DSH宿主模式先调用附件服务保存实际图片字节，再将持久化附件引用交给模型流接口；不会把图片占位文字当作图片，也不需要虚构本机/v1接口。QQ开启“读取本会话图片”后，支持图片的当前聊天模型可直接收到本轮图片，最多3张、合计8MB。纯文字聊天模型可通过图片工具调用单独指定的宿主视觉模型。下载过期或格式不支持会明确提示未加载；重试沿用已提交附件，不重复追加。配置连接或关闭来源权限时，尚未提交的画面不会继续送往原连接。

屏幕采集在授权撤销后不再提交理解；卸载插件或取消请求会停止采集。屏幕/摄像头使用云端模型时，选中的画面会发给所选服务。默认关闭。

B站视频从平台提供的CDN地址获取有界媒体，拒绝陌生地址和重定向。视频下载上限64MB，音源32MB；长片或受权限限制的内容可能失败，不绕过平台限制，也不以标题理解冒充真实画面。

## bot自主使用与平台互通

- `starr_see_now`：管理员允许的屏幕或摄像头，按次采集。
- `starr_bili_watch`：允许公开资料读取后，分析BV号对应视频的真实关键帧。
- `starr_song_source`：同时允许公开读取与音源入库后，将BV视频音轨裁为45秒内片段加入当前角色曲库。可先用B站搜索找候选，再入库、翻唱，最后通过QQ唱歌工具发送。
- `starr_bili_social`：主动评论视频、向已联系且在管理员白名单内的对象私信、发布文字动态。各操作单独默认关闭，遵守额度、冷却与持久去重。
- QQ新增在线/离开/忙碌状态、空间文字说说、当前私聊好友备注、指定QQ群分类标签；原有拍一拍仍可用。每项独立授权。群分类标签并非个人好友标签。

同一角色的QQ/B站会话使用同一套检索与关系数据。共享区提供一键共享当前角色全部有效记忆，并记录可撤销批次；共享后单条资料又改变时，拒绝整批盲撤销。新记忆可由管理员设为来源会话私密或角色共享。主人身份必须来自管理员的QQ/B站绑定，不从旧身份笔记自动授予。群聊与公开评论不获得主人私聊的历史访问范围。

“检查平台与记忆互通”只读核对登录、角色绑定、数据库、共享记忆及分享目标授权，不再借检查按钮执行到期外发任务。平台内容编号表示接口接受的回执，不能保证客户端可见或审核通过。结果不明时保留待核对状态，不自动重复发出。

## 记忆与注入

自动QQ/B站来信、定时活动及记忆任务的消息正文包含本轮完整角色提示、上下文与实际来信，便于在宿主查看。初始快照不再重复塞进运行时上下文；同轮工具更新记忆或会话接续后，仍会刷新。

记忆只用同一套数据库检索。06-概览用于周/月/年概览；07-自我概览用于角色对自己的整理；日级记录归入05-日记。带日期的日记标题不再叠加日期。旧工具操作流水可恢复归档，不影响原有重要度、置信度、锚点和关系编号。原“溯源知新”从日常导航移除，旧字段对照保留为文档。

bot可调整管理员已经允许的日常参数，包括记忆衰减/锚点、近期注入范围、状态摘要、语气与音色、唱歌推理参数、B站兴趣词等。路径、程序、凭据、主人绑定、外发权限、默认共享范围与自身授权均由管理员控制。

## 密钥与能力边界

Windows网页可录入当前角色、当前能力的API密钥，由当前Windows用户数据保护API加密保存；接口不回显原文，分发包不包含凭据。已有环境变量优先，独立连接不会继承共用密钥。其他系统使用环境变量方式。

TTS情绪通过支持的instructions参数传递，最终语气取决于所用模型；不承诺任意远程服务都能表现全部情绪。未实现通用云端训练或通用云端SVC。旧版远程音频字节节点兼容保留，实际节点需单独验证。

旧配置并未全量迁入：411项旧字段的逐项处理状态见 `LEGACY-V017.md`。其中仍待实现的能力不能因移除旧迁入导航而视为已上线。
