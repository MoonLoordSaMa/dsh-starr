# v0.2.4 页面与配置位置

导航采用诗意名称并配普通说明；功能标题、字段与操作按钮使用普通名称。下表列出全部 22 条路由；其中 B站有一个主入口与两个内部标签，因此左栏不会显示三份重复入口。

| 聊天       | QQ 连接与群聊  | `#qq`              | SnowLuma、账号、模型、允许名单、群成员与拍一拍；连接专用保存 |

页面底部的统一保存栏只提交本页角色配置；角色资料、QQ连接、账号登录与资源操作采用各自明确的保存按钮。不要把连接检查、凭据保存和模型推理验证视为同一步。

搜索在左栏下方，也可从首页打开。字段命中后会展开所属高级组，滚动并聚焦字段。旧 `#conversation`、`#host-chat`、`#qq-private`、`#qq-group`、`#chat-context`、`#memory-sync`、`#platforms`、`#browser` 地址仍可打开，分别归入聊天、QQ、日记设置或查找设置；不恢复已退役功能。

桌面版将笔记列表与全文并排；窄屏选择一篇后进入全文，可用返回按钮回列表。长正文保留原文与换行，阅读区可独立滚动。移动端导航关闭时不进入键盘焦点序列；打开导航、查找与表单不应制造横向滚动。

状态取自当前角色真实接口。没有接入宿主时显示独立预览和具体缺失条件；刷新失败保留上次数据并注明过期。页面中未配置的可选能力不统一渲染为故障。
