# v0.2.3 视觉与消息读取修复

复杂截图、视频关键帧分析可能耗尽旧默认值1000的输出令牌额度。宿主以 `max-tokens` 结束时，旧版将其归为 `INVALID_REQUEST`，从而误提示“模型拒绝了请求格式或当前能力”，容易被理解为模型没有视觉能力。

- 默认视觉输出令牌上限调整为4096；管理员已经保存的自定义上限仍按原值执行。部分推理模型的思考也消耗这项额度。
- 正确识别宿主的 `max-tokens`、兼容服务的 `length`，提示到视觉页调高“视觉输出令牌上限”。未完成的回答仍明确失败，不作为成功结果返回。
- 通用请求拒绝提示改为检查宿主日志和参数，不再据此推断模型不支持图片或工具。
- QQ和B站会话专用工具统一在返回边界转换为无损JSON，清除可选字段里的 `undefined`。原始消息保持完整，异常、会话绑定及成功回复后继续接听的语义保留。

回归覆盖复杂图片分析被截断、默认及自定义上限、兼容接口半截回答、消息及历史包含可选空值、异步失败、B站共用工具，以及QQ连续接听。真实账号验证记录随本次修复交付保存。
