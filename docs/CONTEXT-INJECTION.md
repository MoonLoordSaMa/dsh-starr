# 言外之意：上下文注入

这页配置控制绑定该角色的 Starr-chat 会话。QQ、B站与网页角色预设共用同一注入服务；没有绑定角色的 DSH 管理会话不受影响。

角色预设使用独立的完整角色系统提示，保留管理员填写的人设原文，并约定自然直接回应、如实使用工具。宿主的工具执行约束、身份校验、文件权限和审批规则仍然有效。普通管理员绑定会话继续使用宿主原有的系统提示组合。

每次模型请求前，插件根据可信会话身份重新读取当前人设与配置，生成会话边界、接续摘要、可见记忆、心理状态与目的。工具在同一轮里写入的新记忆、接续摘要会在后续请求刷新。上下文总开关关闭时保留角色核心和会话边界，停止动态资料注入；修改配置无需另开会话。

自动召回区分相关话题、最近经历、最近日记与长期锚点。单纯叫角色名字、打招呼不作为泛匹配检索词；不相干的锚点不会冒充话题命中；概览的导入时间不作为最近经历。所有通道均受当前会话可见范围和字数预算限制。旧记忆是历史资料，不能覆盖当前人设，旧故障不能自动当成当前故障。

主动搜索返回编号、元数据和每条最多 600 字符的摘录，长文以 `truncated` 标记；全文通过 `starr_memory_read` 按需读取。此限制不影响记忆库原文及网页完整阅读。

右侧核验区展示两种信息：下一轮的生成预览，以及最近一次完成的宿主模型响应之前提交的系统提示和运行上下文的核对结果。预览不会生成“已生效”记录。核验只保存字数、记忆编号、配置修订号和摘要指纹，不额外保存一份聊天正文；核对时只采用响应之前最新的系统提示与运行快照。修改配置后，旧核验记录会提示等待下一轮请求。

核验确认资料已提交到宿主模型请求，不代表模型一定提到每条记忆或逐句遵循某种语气。上下文字数预算仅覆盖 starr 资料，不能等同于整个 DSH 历史窗口或服务商令牌数。已有长工具结果仍保留在宿主历史中；本次修复不会删除用户聊天。
