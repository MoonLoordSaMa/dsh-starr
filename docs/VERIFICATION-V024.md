# v0.2.4 验证记录

本版在独立测试目录、合成角色与生产备份的独立审核副本中验证。生产 DSH 没有安装或启动本版，真实账号没有发送测试消息；因此下面的接口和网页结果不能代替上线后的平台联调。

## 自动化验证

本地 Node 测试共 **244 项，全部通过**。运行时生成文件一致性、TypeScript 类型检查、前端生产构建、格式检查与发布审计另行执行。

本版新增的主要验证包括：

- 自由笔记修订实际落库与重开读取，修改前正文审计，旧修订冲突，来源与可见性不变，拒绝改写日记和跨角色/会话修订。
- 新群与新私聊能召回已共享的长期理解；来源私密笔记不泄露；旧非日记类型兼容自由笔记查询，注入不超过配置预算。
- 同来源后台会话复用、冷恢复、运行中拒绝抢用、角色来源隔离、正常用户标题保留；驱动重复执行和失败后释放临时工具与监听。
- 群自主参与开启时普通未 @ 消息可交模型判断；仅观察、关闭自主群参与、暂停和禁止群保持有效。
- Tabbit 配置与固定周月年回顾没有可执行入口；旧配置值不会重新启动退役任务。
- 页面常用字段直接可见；整页配置一次提交、持久化与修订冲突保护。
- 记忆审核脚本在 125 篇旧笔记上完成多批同步，保留原文、日记与引用，不修改输入备份；拒绝已有目标、输入输出重叠、来源遗漏、跨私密范围合并和不支持的旧目录格式。

## 浏览器实测

使用 Tabbit 中一个专用测试页，访问本机独立预览服务；全部角色、记忆与修订样例为合成数据，无生产桥接或后台任务。

| 场景           | 已观察结果                                                                                                    |
| -------------- | ------------------------------------------------------------------------------------------------------------- |
| 桌面路由与布局 | 22 条路由可展开，无页面脚本崩溃和横向溢出；这项检查验证导航与布局，不表示各平台业务全部联调通过               |
| 配置保存       | 接听时长修改后保存，刷新保留；合成 409 冲突时显示原因并保留草稿，可还原                                       |
| 离页           | 有未保存配置时出现确认，取消后留在原页                                                                        |
| 搜索           | 日常说法“她为什么没反应”找到对应入口；工作区字段搜索跳到聊天页，展开高级组并聚焦实际字段                      |
| 旧地址         | 会话、私聊/群聊、上下文、同步、平台和浏览器旧路由归入当前入口                                                 |
| 记忆长文       | 约 1.56 万字符全文保留；桌面阅读区高 550 像素、正文滚动高度超过 3 万像素，实际可独立滚动并用键盘翻页          |
| 状态失败       | 成功读取后模拟 503，保留旧数据、显示刷新失败、状态点改为旧数据颜色；恢复请求后清除过期状态                    |
| 角色隔离       | 切换合成角色不展示前一角色的长期理解；空角色显示空记忆，搜索无结果有明确提示                                  |
| 按钮交互       | 悬浮有六颗四芒星和共享折射画布，可见按钮均有交互标记；键盘聚焦有辉光，不依赖边框线                            |
| 减少动态       | 系统减少动态启用后仍有六颗静态星，运行中的星动画为零，无折射画布                                              |
| 手机           | 390 × 844 下抽查 14 页无横向溢出；导航打开时背景不可聚焦，Escape 关闭并恢复焦点；保存栏不溢出，长文仍完整可读 |
| 平板           | 768 × 1024 聊天配置页无横向溢出                                                                               |

测试主动注入的 409、503 属于失败场景，不是“没有任何请求失败”。快速切页取消旧请求出现 `ERR_ABORTED`，独立预览缺宿主的接口返回具体缺失条件；这些结果没有冒充真实 QQ/B站成功。
