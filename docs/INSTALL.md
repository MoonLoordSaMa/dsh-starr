# 安装与更新 0.1.9

新用户使用 dsh-starr-0.1.9.tgz。包内带 DSH 自动启用声明，安装后自动加载服务、挂载侧栏入口并注册 Starr-chat 预设，无需手写 YAML 或创建目录联接。

## 新安装

在 DSH 支持本地压缩包的安装入口选择 .tgz，也可运行：

```powershell
dsh plugin --profile desktop add '你的下载目录\dsh-starr-0.1.9.tgz'
```

desktop 换成实际配置名称。安装后重新打开 DSH，点击侧栏 starr。首次调试依次检查 SnowLuma、访问令牌与允许名单，创建角色与人设、记忆库及备份目录，选择模型。B站和扩展媒体都可跳过；只有明确启用 QQ 并完成向导才开始处理消息。

只有 ZIP 时先解压，选择解压后的 package 目录安装，或运行 dsh plugin --profile desktop add '解压位置\package'。当前 DSH 不支持将 ZIP 直接当作 npm 压缩包安装；ZIP 是归档副本，.tgz 是可直接安装的格式。

不需要安装仓库的开发依赖。前端已构建，后端只使用 Node 内置模块且不直接导入 TypeScript。最低 Node 24，宿主接口按 DSH 0.2.1-rc.5 核对；未来宿主版本仍需验证。

## 先跑起来，再补能力

- 聊天使用 DSH 已登录模型；在「她的模样」编辑角色。
- 听写选择免费本地 Whisper，点击准备，再上传真实音频验证。需要 Python 和首次联网下载；也可使用远程兼容服务。
- 本地 Breeze 只填安装文件夹，发现后确认填入，再选音色试说。参考录音建立音色可选，不是所有引擎都支持训练或参考音色。
- 视觉默认沿用 DSH 的图片模型，无需重复填写地址与密钥；屏幕与摄像头需单独授权。
- 唱歌页填 SoulX 安装目录，导入音源与参考音色，再生成45秒内翻唱验证。需要本机兼容引擎与权重。
- 远程媒体填写兼容地址、准确模型名与密钥；说话还需要服务支持的音色编号。不同服务私有协议与音色训练不自动统一。

发现只盘点文件，不安装引擎、不执行程序，也不等于推理已通过。没有本地引擎可跳过，之后再配。细路径、凭据和权限由管理员修改，放在高级配置。

## 更新已有安装

安装新版 .tgz，保留运行目录，完全退出并重新打开 DSH。网页应显示 v0.1.9；只刷新网页可能仍使用内存中的旧后端。

旧版手工加载的用户先确认原有 starrcore 节点，不要同时保留重复的手工加载和自动启用节点。插件运行锁会阻止双实例接管平台，但仍建议检查并保留一个实例。自定义 dataRoot 和会话绑定应保留；普通新安装不需要填写。

升级不移动记忆库、不重建人设、不覆盖个人表情，不自动扩大共享范围和授权。

## 自主行动

首页「她今天做了什么」展示时间线和用量。在「主动目的」可预演、暂停和修改范围。默认 L0 只观察；L1 仅可信且已联系过的主人QQ私聊；L2 增加已授权公开阅读；L3 增加逐项授权B站社交。后台不开放管理命令、屏幕或摄像头。

安静时段、近期互动、主人明确说忙、每日与每轮预算、未知用量、连续失败都会让执行器停下。未知发送不自动重试。一键暂停阻止新的目的、B站定时活动与星桥后续外发；不能撤回平台已受理请求，普通来信回复仍由会话设置控制。

## 验证边界

端口在线、模型文件存在、配置保存与真实调用不是同一状态。必须用实际音频、图片或允许名单来信验证。费用是宿主报告用量与管理员单价的估算，媒体服务另计。

包内不含角色、记忆、聊天、个人表情、凭据、测试数据或权重。可用同目录 .sha256 和文件清单核验。更多变化见 V018.md。
