# v0.2.0：群聊修复、日常主动性与暖金星庭

日期：2026-11-06。安装文件为 `dsh-starr-0.2.0.tgz`；安装方式见 [INSTALL.md](INSTALL.md)，验证范围见 [VERIFICATION-V020.md](VERIFICATION-V020.md)。

## QQ 群聊

- 修复底层连接只转发普通消息、遗漏戳一戳通知的问题。群聊戳当前机器人时，通知会进入原有的对象授权、事件去重和回复链路；戳其他人、来自未授权群的通知不会触发回复。
- SnowLuma 私聊戳一戳优先使用 `sender_id` 识别发起人，避免将通知中的会话对象误认为发起人。
- 普通群聊回复也支持按空行分条，无需模型必须选中特定分条工具。单换行保留；超过配置条数时合并尾段，不丢弃正文。
- 群内引用和 @ 只放在首条，每条保留独立回执。已发前缀不会因后续失败而整组重发，私聊继续按其独立权限控制。

## 主动行为

新增“日常主动评估间隔（分钟）”，默认 180 分钟。开启主动行为后，即使没有强烈情绪或高分需求，也可定期回顾近期真实经历、约定和已授权的机会，选择交流、探索、整理或反思。情绪影响语气与负担，平淡、低落和乐观均可行动。设置为 0 可关闭日常机会，仅按明确目的与需求触发。

主动机会仍受范围授权、安静时段、近期互动、明确忙碌或休息表达、冷却、预算与失败保护约束；没有值得做的内容时可以选择安静。默认仍只观察，不自动扩大 QQ 或 B站权限。

修复同类高分需求当天已评估后阻塞其他候选的问题；不急迫的旧需求目的也不会挡住日常机会。修复工具已取得发送回执、执行器未重复返回结果时，被误记为“选择安静”的问题。回执与主动时间线按实际结果保存。

## 页面名称与可读性

- 只有功能导航保留诗意名称，例如“星海拾忆”“山海来信”“星庭设色”；页面标题、表单、按钮、状态、详情和错误说明恢复直接表达。
- 提高正文、表单、导航说明和辅助文字字号及对比度，首页第二行标题改为清晰的暖金色。
- 首页和功能页文字随滚动保持完整不透明度；文字区域增加局部衬底，亮色星流经过时仍能辨认。
- 补齐标签、按钮和状态控件的局部背景模糊；移除内容祖先的常驻合成提示，避免背景采样受阻。
- 轻动效保留面板 7 像素、独立控件 4 像素的模糊；普通模式默认分别为 12、6 像素。具体数值仍跟随外观设置。面板内部控件沿用父面板玻璃，减少重复滤镜。
- 全屏遮罩由首屏 0.16、滚动后 0.32，调整为 0.12、0.24；可读性主要由文字自身和局部容器保证。

## 暖金星庭

星空、银河、雾色与补光向暖杏金协调，远山保留青绿层次。九股丝绸增加顺流光脉、四芒闪点和拖尾，普通模式沿路径光粒由 108 个增加到 270 个，轻动效为 126 个；空气浮星没有额外加密。星流仍沿原有曲线汇聚并避让内庭粗柱。

增强光效写入原有着色器，丝绸与行进光粒仍使用两次绘制。减少动态时停止持续星环与星流动画，恢复后继续运行。性能数据与限制见验收记录。

## B站与 QQ 协同

修复跨平台分享遇到已发记录时提前返回、阻塞后续动态或其他收件目标的问题。多个 QQ 目标按冷却分次处理，已发目标不会重复接收，也不会挡住后续目标。

B站视频分享必须取得明确消息编号才记为成功；缺失编号时持久记录“待核对”，同一视频不会自动重发。扫码登录、资料阅读、视频理解、定时活动、内容管理和平台协同的自动化覆盖及真实联调边界，分别列在本版验收记录中。

## 更新与源码

安装新版后完全退出并重新打开 DSH，使内存中的后端也更新。保留个人运行目录、角色与记忆库，不要用源码压缩包覆盖这些数据。

本版移除全局诗意名称转换模块，源码包按当前工作区生成，已删除的旧源码不会混入发行清单。上传 GitHub 时应让仓库文件与本版源码一致，同时保留 `.git` 历史；不要仅叠加文件而留下本版已经删除的旧模块。
