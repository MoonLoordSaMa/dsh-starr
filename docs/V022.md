# v0.2.2 · 看得见的心意

本版让角色把浏览、听写、翻唱和创作接到真实行动上。目的、内容与时机继续由角色决定，插件提供可核验的能力和结果。

## QQ 语音接收

- 开启“听写本会话语音”后，默认在回复前自动转写本批最多三段语音。其余可按需调用听写工具。
- 同批转写结果缓存，后续读取不重复识别。回复后等待收到的新语音也走同一流程。
- 保留 QQ 原始录音编号；桥接端需要时，通过 `get_record` 转成 WAV。失败保留具体原因，角色不能猜占位消息内容。
- 语音识别页直接提供接收授权、自动转写及模型配置。
- 听写提供说话内容，没有新增持续麦克风监听、音色识别或完整语气理解。

## QQ 连续接听修复

- 每次成功回复后，在同一回合继续接听 2–3 分钟，默认 150 秒；收到补充并回复后重新计时。通过“基础会话 → 回复规则与节奏”可直接配置。
- `starr_qq_wait_message` 支持反复接听。模型漏调时，宿主在提交回合结束之前自动接听；没有新来信时不再请求模型。
- 续接的文字、图片与语音进入当前回合的下一步收件箱；图片保留原生内容块，语音沿用实际听写，不重新投递整份初始会话提示。
- 同一会话的新批次继续保存独立发送回执；其他好友、其他群的消息不会串入。取消、暂停或撤销授权会结束接听，未处理的新消息继续保存在收件箱。
- 等待结束后才结束当前回合。超过等待窗口的新消息会正常开启下一回合；图片和有效对话历史本身仍会占用上下文，不承诺固定比例的节省。

## 连续浏览

- `starr_browser` 提供 open、observe、click、type、scroll、back、close。
- 保持本会话自己的 Tabbit 页面，返回可交互控件编号，使用本次观察到的编号继续操作；不向角色开放任意脚本。
- 跨回合再次取得原有标签；过期元素需要重新观察。不同来源会话独立，不操作用户已有标签。
- 查询待定请求的原回执，不重新提交同一次操作。关闭和闲置回收只清理插件创建的页面。
- 不限制域名。登录、验证码与付款仍需要用户完成对应网页操作。
- `starr_browser_read` 保留一次性正文和截图阅读方式，视觉继续沿用现有模型。

## 自选歌曲与主动翻唱

角色可以自行选歌，经已有搜索、音源入库和翻唱工具取得真实成品。在主动回合结束时，以 `songRenderId` 向当前可信来源群或已绑定主人发送语音，无需先收到点歌请求。

QQ 翻唱语音独立发送，配文保存在进展中，避免桥接端拒绝混合消息。发送前重新核对授权，沿用已有作息、暂停和实际回执处理；结果不明不重发。歌曲片段仍遵循现有时长与音源可播放范围。

## DSH 原生文件读写

- 在斯塔预设中挂载 DSH 原生文件、搜索与工作区规则插件，并解除误将文件工具当作管理操作的拦截。直接使用 `read`、`write`、`edit`，通过 `glob`、`grep` 查找资料，`read_image` 阅读本地图片。
- 主动回合同样可使用原生文件工具，自行读资料、写随笔、修改文档，不再要求先收到用户请求。正常写作无需专用便笺接口。
- 新建的 QQ、B站、主动与记忆任务会话使用角色文件工作区。默认在数据目录内的 `workspaces/<角色编号>` 子目录，和数据库文件分开保存。
- “基础会话 → 回复规则与节奏 → 上下文、工作区与记忆召回”直接提供角色文件工作区配置及原生工具挂载状态。管理员可为新会话选择已有工作区；角色不能修改路径配置。目录切换不扩大 DSH 已有会话的文件授权，原生沙盒拒绝仍如实返回。
- 旧版自动会话若仍以插件运行库为当前目录，通过 DSH 原生工作目录服务迁移；用户已自行选择的项目目录保留。
- 使用宿主文件服务原有权限、先读后改及修订校验。遵循目标工作区的 `AGENTS.md`，文件修改以实际执行与读回为准。
- 绘图与文档创作可以按已有工具能力写出 SVG 等文件；本版没有新增通用文生图模型或专用桌面便笺页面。

## 能力自知与配置

新增 `starr_capabilities`，区分“未开启”“配置缺失”“具备调用条件”。角色系统提示只包含简短状态，不重复注入整份诊断；具体原因按需读取。配置完整不代表后端已实际成功，旧故障不作为永久能力结论。

四个工作区保持基础会话、感官、主动能力、记忆的功能归属，不表示执行顺序。新能力不增加固定晨报、预设任务或手工记忆分类。

## 升级

安装 `dsh-starr-0.2.2.tgz` 后重启 DSH。旧数据结构保留；新安装默认关闭连续浏览交互，已有阅读、唱歌、记忆权限保持原值。原生读写沿用宿主文件工具，按需选择角色工作区。生产角色的听写服务需独立检查配置，不能将普通聊天模型地址等同于语音识别服务。

2026-11-07 修复包同时修正旧 QQ 会话目录迁移的宿主服务访问方式，解决来信已接收却在调用模型前失败、不回复的问题。已补测未注入目录服务的实际宿主会话恢复流程；缺少可选目录服务时仍可正常对话。
