# 架构与数据

`src/starrcore` 管理角色、统一配置、SQLite 与记忆关系；`src/host` 暴露可信角色上下文的工具与 DSH 适配入口；`src/conversation` 管理平台会话、上下文、可见范围、预算与用语证据；`src/qq` 与 `src/bili` 管理收件、回执与活动；`src/jobs` 管理定时任务；`src/media` 实现兼容媒体、本地进程和翻唱请求；`webui` 负责界面与场景；`migrations` 只读核验旧完整备份。

运行数据库保存安装目录、角色人格、角色配置与配置修订审计；配置更新和审计在同一事务内。每角色的记忆、图边、投影待办、状态、状态审计、目的与表情元数据保存在该角色自己的 `memory.sqlite` 中。表情原文件在 `attachments/expressions`。

保存记忆与登记投影待办在同一个 SQLite 事务中；成功返回表示已提交。投影失败不丢失原记录。笔记使用稳定编号作为文件名，清晰标题与来源在正文/元数据中；显式关联输出双方 `[[编号|标题]]`，语义建议不冒充明确双链。

笔记输出前比对上一次投影的 SHA-256。外部编辑被检测到时停止覆盖，保留待处理项。外部修订合并还未实现，用户须先处理冲突后重试。

普通记忆的新鲜度使用 `2^(-age/halfLifeDays)`，与重要度相乘得到初版召回分数。锚点保留重要度，原文不会因衰减被删除。关键词使用子串匹配支持中文短词；可见范围、相关度、权重与时间衰减在数据库中筛选并排序，只加载最终少量完整正文。全文三元索引已建，但尚未接入主查询与重建入口，向量索引待实现。

页面切换角色仅改变观察对象。请求地址和工具上下文固定携带角色编号，旧异步响应由地址校验与取消信号隔离，不能覆盖新角色。目的创建不会触发外部动作。

网页接口只监听本机，检查 Host 与跨站 Origin，生成响应不携带明文密钥。当前不提供远程公网管理；媒体凭据由环境变量引用提供；Windows 的 QQ 令牌与 B站 Cookie 可由当前用户的 DPAPI 加密保存，接口不回显。

SQLite 快照是数据库事务一致的。笔记、附件和资料文件逐项复制并记录校验清单，跨文件不是全局原子快照；恢复流程需要重新核验。此限制也适用于并发运行中的备份。

QQ 与 B站按账号和对象持久登记为 Starr-chat。平台、日记和活动使用原生 DSH Agent；核心工具只从可信宿主上下文取得角色与会话。未绑定普通会话不注入角色工具。独立任务具有运行租约、有限并发、超时和卸载中止；回执不明与中断分开保留，避免不确定外发自动重放。
