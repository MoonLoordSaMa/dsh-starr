## 浏览器验证

使用 Tabbit 检查独立合成角色的页面。桌面 1440×1000 和窄屏 390×844 验证首页、功能入口、按钮布局及文字；窄屏没有横向溢出。

- B站连接、浏览、动态、跨平台分享、QQ 群聊、回复规则、主动行为和外观页均能打开，页面标题使用直接名称。
- 普通模式面板背景采样为 12 像素、独立控件 6 像素；轻动效保存并刷新后为 7、4 像素。内部控件沿用父面板采样。截图确认文字容器覆盖范围内的建筑发生模糊。
- 标题和正文保持可见，首页第二行标题为暖金色；文字不因滚动退为低透明度。亮色星流后方仍有局部文字衬底。
- 路由切换保留一个背景画布；系统减少动态时星环的两层旋转角保持不变，恢复设置后继续运行。
- 普通桌面完整场景约 41 次绘制、285,649 个三角形、3,186 个点粒子。丝绸与沿路径光粒共两次绘制。没有将帧间隔或处理器提交耗时解释为稳定前台帧率保证。
- 独立控制台没有 DSH 平台驱动，QQ 和部分 B站操作入口会明确报告尚未接入；这不是有效账号功能已经通过的证明。

## 真实平台验证边界

本机已打开的 B站主页可读取，显示视频卡片，没有观察到访问拦截页；此检查只证明网页可访问，不证明 dsh-starr 后端会话凭据有效。

正在运行的 DSH 本地接口对未认证请求返回 HTTP 401，因此本轮未通过该接口读取生产角色状态或完成真实账号联调。没有从浏览器提取会话凭据，也没有向真实 QQ 或 B站发送测试消息、评论、弹幕或动态。
