# v0.1.5：功能整理与界面验收

本版把配置按使用场景拆回功能页，增加角色人设、B站扫码、记忆维护与跨平台星桥，并优化常驻三维背景。版本号为 `0.1.5`；版本号本身不代表所有历史能力或真实外部服务已经验收。

## 从哪里开始

已安装用户更新后重新启动 DSH，再从侧栏 starr 进入。新用户继续使用七步新手调试；不需要安装 GSAP 技能或前端开发依赖。

## 新增与恢复的运行能力

- **角色编辑**：独立入口编辑名字、人设和提示词。保存时校验修订号；配置发生并发更新时保留未保存草稿，供用户选择重新载入。
- **B站扫码**：在本机生成二维码，通过官方接口查询扫码状态，支持取消和过期；登录不依赖回复模型。确认账号后保存到现有凭据服务，Cookie 不回显。Windows 使用当前用户系统加密。
- **B站内容管理**：本机草稿、文字和图文动态预览、编辑、删除、点赞，以及资料、搜索、历史和收藏目录。外发需要预览确认凭证，并校验角色、账号和正文；重启后无法确认的发送记录保留待核对状态。
- **星桥**：将已读视频或本账号新公开动态分享至明确授权的 QQ 目标。默认关闭；目标必须同时通过 QQ 允许名单和星桥名单，支持额度、间隔、去重、回执和停止。首次动态检查仅建立水位，不刷旧动态。
- **记忆维护**：可恢复归档、全文索引重建、主题关联建议；外部 Obsidian 修改先比较预览、校验文件哈希和修订号，再导入正文与显式双链，旧正文保留审计。不会静默覆盖冲突。
- **QQ 社交工具**：读取当前群成员与活跃者、读取当前角色人设、本机问题反馈、对当前批次真实发言者拍一拍。工具有独立开关，并绑定可信会话目标。
- **音色与曲库维护**：列出本地 Breeze 音色、回收当前角色音源、清理生成成品；默认参考音色受保护，清缓存保留原音源与参考音色。
- **核心工具**：新增记忆归档、音色列表、链接解析与 B站公开资料读取，核心共 20 项；QQ/B站会话的额外工具仍由所属驱动按权限提供。公开资料工具不能读取私人历史或收藏。

## 配置之间的关系

角色人设决定会话身份；上下文页决定每次注入多少；共享页决定不同会话能看见哪些记忆；QQ/B站页决定连接、对象与平台权限；回复页决定唤醒、延迟、额度；星桥只使用同时获得两层授权的目标。

媒体共用连接提供默认地址与凭据环境变量引用，各能力分别配置模型和音色。远程唱歌依然是专用字节协议，不能把聊天模型地址当成唱歌节点。可在关联入口间跳转，也可在群星索引搜索字段名或用途；全部 251 项角色配置均有功能页归属，QQ 全局传输配置另外维护。

角色自改配置仍受 `permissions.botConfig` 和字段白名单约束。不能修改路径、密钥、管理员、程序或自身授权；本版不扩大这些权限。

## 视觉与性能

统一导航、分组标签、下拉与圆角；列表和文字入口采用轻量表面，主要操作保留局部高光，模糊限制在控件覆盖范围。功能页诗序与滚动场景由 GSAP 管理，切页清理动画和观察器，减少动态模式停止持续运动。

星光庭院使用程序生成的天空、云带、细颗粒、台阶、石柱、树枝与近景。按功能分组提供不同的相机推进、侧移和抬升；切页复用同一个背景画布。静态石柱与台阶使用实例批次，树枝合并绘制，避免逐物体提交。

在本机同一合成预览视角中，背景绘制调用从约 140 次降到约 60 次。该数值说明提交次数减少，不等于 GPU 帧率保证。自动品质根据 JavaScript 渲染提交耗时调整像素比；轻量模式降低更新频率，隐藏页暂停。大库、低端 GPU 与长期运行仍需要实际验收。

## 历史功能迁移范围

411 项旧注册字段中：197 项归并到实际配置，21 项交给 DSH，46 项机制退役，147 项仍待接入。140 项旧工具、命令与任务盘点中，110 项由新入口承接，30 项仍待接入；保留 243 项额外声明供复核，不把声明数量当作配置数量。

“承接”表示新服务提供相应入口或主要用途，不表示保留旧工具名、旧参数、旧引擎或所有边界行为。待接入项目没有伪造可用开关，也不会自动照搬旧配置值。逐项对照见 [LEGACY-V015.md](LEGACY-V015.md)，有效字段的默认值与范围见 [CONFIGURATION.md](CONFIGURATION.md)。

## 验证边界

本版自动测试与浏览器操作使用独立合成数据，覆盖持久化、角色隔离、并发冲突、取消、未授权调用与失败路径。浏览器检查七个工作区、全部功能页和多个屏宽，并检查人设草稿、配置搜索、扫码展示与画布复用。最终测试数量和包校验以本次仓库外交付报告为准。

真实官方二维码生成已检查，返回官方扫码地址且未取得凭据。尚未实际手机扫码登录；B站真实账号写入协议、QQ真实送达、真实付费模型、本地模型质量和远程唱歌节点仍需按账号与设备分别验证。合成协议通过不能替代这些实号验收。本版未公开发布到插件市场。
