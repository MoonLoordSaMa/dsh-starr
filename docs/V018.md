# v0.1.8：能装上、能配置，也能解释自己的行动

## 安装与可复制性

加入 dsh.bundle 与默认补丁，新安装自动启用，无需手写加载配置。共享状态算法在构建时生成后端 .mjs，测试检查生成物同步；发行包不包含 TypeScript 或开发依赖。发行 .tgz、归档 ZIP、SHA-256 和文件清单。固定归档元信息让 .tgz 可重复生成。安装验证使用独立 DSH 主目录与实际解包副本，不通过原仓库联接。

## 新用户配置

本地配置收敛到一个引擎安装目录、确认发现结果、音色或参考素材、真实试用。端口和细路径放在高级配置。发现结果不会标成「能力已验证」。首次向导的候选可真实写入待保存配置，修复原来回调未使用的问题。

免费 Whisper、DSH视觉模型、远程兼容连接保留现有实现。说话增加常用音色入口。不会宣称任意远程服务都兼容参考音色训练或本地 SVC 协议；扫描不自动安装引擎或执行程序。

## 状态、表达与接续

状态注入增加表达指引：低精力时缩短表达，紧张时减少追问，急切时调整节奏。已开启的 QQ 回复停顿按状态变化，仍受最大时长和中断约束；原本零停顿保持立即发送。分条与安静继续由会话工具和配置控制。

会话摘要和未完事项进入下一轮。主动主人私聊还会携带同一可信对象上次的接续，避免平白重启话题。跨平台共同经历继续依赖共享记忆授权，不把另一私聊公开。

## 有边界的目的执行器

原来的目的评估继续保持只读；独立执行器完成「预演 → 按当前权限与预算执行 → 保存结果」。驱动力可提出候选，已保存的明确目的也可被处理；没有合适时机可安静，不是每30分钟必发一条。

默认 L0，只观察。L1 可信主人私聊，L2 公开阅读，L3 逐项授权社交。管理操作留在 DSH 管理会话；后台目的不能开终端、写插件、动凭据或启动屏幕和摄像头。角色不能自行修改主动范围、预算和授权。

调度器检查安静时段、冷却、最近互动、主人明确说忙、来信积压、每日评估／外发次数、每轮模型请求／工具调用次数、实际令牌用量与连续失败。每次调用和发送前重新核验，不依赖提示词承诺。每个目的仅自动评估一次，未知回执不自动重试。管理员确认故障只解除失败熔断，不清除预算或重发未知消息。

一键暂停停止新的目的执行、打断正在进行的目的回合，并让 B站定时浏览、发布与星桥在下个检查点停止。不关闭普通来信回复，不撤回平台已受理的请求。

## 今日与成本

首页与主动目的页展示当天记忆、日记、主动目的、B站活动、星桥和记忆整理。可看到行动或安静的理由、失败与未知回执、每轮请求与工具计数。时间线按角色时区归档；用量与费用明确标注近24小时窗口。

费用来自宿主实际报告的令牌和配置单价，不是服务商账单；媒体费用另计。未知用量不当作零，后台目的遇到用量缺失后停止后续模型请求。

## 失败反馈与边界

模型失败分为登录／凭据、额度、繁忙／限流、网络、超时、上下文、模型不可用和请求格式。分类读取嵌套根因，界面只返回固定说明，不回显服务端原文、密钥或路径。仅有 TRANSPORT 时无法证明更深的原因，保留网络排查提示。

本地 Breeze/SoulX 需要兼容环境与权重，文件存在不代表跨设备推理成功；参考音色依赖引擎自身实现。QQ空间、B站公开操作还受桥接版本、账号权限和平台风控影响；无真实回执不能显示已发送。状态和节奏不代表人类生理或意识。

后台目的与 B站活动、星桥保留各自原有额度，一键暂停统一管理，时间线按来源显示。不会假装全部服务只有一个模型账单。旧411项逐项对照见 LEGACY-V017.md，冲突、移除或未实现的能力不会被改写为已经验收。

实际构建、测试与独立安装记录随交付报告提供，合成平台验证与真实账号验证分别记录。
