# 0.1.6 · 记忆接续与可读目录

旧版导入记忆缺少会话归属时，新版会话只能看到少量新写记录。此版提供管理员确认的主人 QQ 绑定：匹配的私聊可读取当前角色未归属的个人历史。已经归属其他会话的记录、撤回共享的记录和其他角色仍保持隔离，不把所有旧记忆改为共享。

主动调用记忆搜索时，最低自动召回分数不再挡住低分或较久远的旧记忆。新增 starr_memory_status，可查看当前会话可见数量、类别和数据库检查结果；搜索支持 sort=recent。工具返回全文，模型无需获得本地文件或终端权限。

每轮请求在总预算内组合角色核心、会话边界、当前时间、记忆入口、本会话摘要、最近经历、相关话题、最近日记、长期锚点、状态与目的。每条记忆携带编号和原始日期，重复记录只注入一次；摘录逐条保留完整的 JSON（结构化数据）格式。新写记忆可在下一次请求立即参与召回。时间窗口、最近条数、锚点条数和日记补入都可在会话配置中调整。

目录兼容层保留稳定角色与记录编号，支持可读的角色目录和六类中文笔记目录。文件名为「日期 - 标题 - 短编号」，路径映射持久保存；标题修改不会静默重命名笔记。双向链接使用真实笔记路径，同时兼容旧编号链接；外部编辑仍保留冲突，不覆盖人工正文。备份包含路径布局文件。

维护页的宿主状态由实际挂载情况计算。独立预览、宿主来源未就绪和已挂载分别显示，不再固定为待验证。工具、预设与平台驱动状态分别列出；已挂载不代表真实模型、QQ 或 B站外部调用验证成功。

此版共有 256 项角色配置、21 项核心业务工具，平台工具仍由实际授权决定。个人目录、QQ 绑定、表情原图和迁移脚本均不进入插件 ZIP；不会在其他用户安装时套用私人路径。

自动化验证覆盖：主人历史访问与撤回共享隔离、跨角色访问、低分旧记忆主动检索、最近记忆与日记去重、摘录预算、持久化、可读路径、外部正文保护、双链解析和宿主状态。真实账号收发、收费模型及远端唱歌节点的可用性需要在对应环境独立验证。
